#  Multi-Document RAG Assistant

## Project Overview

This project is a Multi-Document Retrieval-Augmented Generation (RAG) Assistant built using Streamlit, LangChain, FAISS, Gemini, HuggingFace Embeddings, and EasyOCR.

The application allows users to upload documents such as PDFs, Word files, Excel files, CSV files, JSON files, text files, and images. Users can then ask questions about the uploaded content and receive context-aware answers generated by Gemini.

The goal of this project is to create an intelligent document assistant capable of understanding document content, retrieving relevant information, and generating accurate responses.

---

# Problem Statement

Large documents are difficult to read manually.

Users often need answers from:

* PDF documents
* Reports
* Excel sheets
* Images
* Word documents

Instead of searching through hundreds of pages manually, this application allows users to upload documents and ask questions directly.

# File Responsibilities

## app.py

Acts as the user interface.

Responsibilities:

* File upload
* User interaction
* Chat interface
* Displaying responses

---

## rag_service.py

Acts as the project coordinator.

Responsibilities:

* Calls all modules
* Controls the complete RAG workflow
* Generates final responses

---

## loaders.py

Responsible for reading uploaded files.

Supported formats:

* PDF
* DOCX
* XLSX
* CSV
* TXT
* JSON
* PNG
* JPG
* JPEG

---

## ocr.py

Extracts text from image files using EasyOCR.

Example:

```text
PAN Card
Aadhaar Card
Scanned Documents
Screenshots
```

---

## chunking.py

Splits large documents into smaller chunks.

Purpose:

* Improve retrieval accuracy
* Reduce token usage

---

## embeddings.py

Converts text chunks into vector representations using HuggingFace Embeddings.

Purpose:

* Semantic similarity search

---

## vector_store.py

Creates and manages FAISS vector databases.

Purpose:

* Store document embeddings
* Fast retrieval

---

## rag.py

Responsible for retrieving relevant chunks based on user questions.

Purpose:

* Context retrieval

---

## semantic_cache.py

Stores previous questions and answers.

Purpose:

* Avoid repeated LLM calls
* Improve performance

---

## rag_prompt.py

Contains the prompt template used for Gemini.

Purpose:

* Control answer generation

---

## llm.py

Handles communication with Gemini.

Purpose:

* Send prompts
* Receive responses

---
